# Sweet Valley Venture — Site Mirror

This repo contains a **static mirror** of [sweetvalleyventure.com](https://sweetvalleyventure.com/), captured on 2026-07-30.

It is a snapshot of the publicly rendered pages, CSS, JS, images, and fonts — enough to view the site offline exactly as it appeared. It is **not** the original WordPress source: there is no PHP, no admin, no database, and no plugin code. To get the real WordPress source (theme, plugins, database), export/migrate it directly from the hosting account (e.g. via FTP/SFTP, cPanel, or a plugin like Duplicator / All-in-One WP Migration).

## Viewing locally

Serve the folder with any static file server, e.g.:

```bash
npx serve .
```

Then open the printed local URL in a browser.
